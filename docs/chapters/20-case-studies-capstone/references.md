# References: Case Studies and Capstone Project

1. [Case study](https://en.wikipedia.org/wiki/Case_study) - Wikipedia - Defines case study research design, case selection, uses, and limitations. Relevant to the chapter's treatment of the MicroSims paper and textbook project as analyzed cases; includes sections on teaching use.

2. [Capstone course](https://en.wikipedia.org/wiki/Capstone_course) - Wikipedia - Describes the integrative final project that concludes a degree program and how it is presented. Supports the chapter's capstone project deliverables, presentation of results, and evaluation rubric.

3. [Multi-agent system](https://en.wikipedia.org/wiki/Multi-agent_system) - Wikipedia - Covers systems of interacting agents, their coordination, frameworks, and applications. Gives background for agent team design, role assignment, and handoffs between agents, with a survey of research areas and architectures.

4. Case Study Research: Design and Methods (6th Edition) - Robert K. Yin - SAGE Publications - Yin is widely credited with systematizing case study method, including the written case study protocol and the logic of replication across multiple cases. This clarifies how to run, document, and compare case studies rigorously.

5. The Checklist Manifesto: How to Get Things Right - Atul Gawande - Metropolitan Books - Draws on aviation and surgical practice to distinguish read-do from do-confirm checklists and to place explicit pause points. A clear model for workflow documentation and review gates in an agent pipeline.

6. [Building Effective AI Agents](https://www.anthropic.com/engineering/building-effective-agents) - Anthropic - Distinguishes workflows from agents and describes prompt chaining, routing, parallelization, orchestrator-workers, and evaluator-optimizer patterns. Directly informs agent team design and skill pipelines, with pattern diagrams and guidance to start simple.

7. [How We Built Our Multi-Agent Research System](https://www.anthropic.com/engineering/multi-agent-research-system) - Anthropic - A real engineering case study of an orchestrator-and-subagent research system, with lessons on prompting, evaluation, and reliability. Models the lessons-learned and failure-case reporting this chapter asks for.

8. [Create Custom Subagents](https://code.claude.com/docs/en/sub-agents) - Claude Code Documentation - Explains defining specialized subagents as Markdown files with their own context, tools, and permissions. Practical reference for implementing the roles, autonomy limits, and handoffs in a one-page agent team design.

9. [Postmortem Culture: Learning from Failure](https://sre.google/sre-book/postmortem-culture/) - Google SRE Book - Describes blameless postmortems, when to write them, and how to share them. Supports the chapter's failure case format of cause, detection, control, and change, with an example postmortem template.

10. [Ten Simple Rules for Reproducible Computational Research](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003285) - PLOS Computational Biology - Sandve and colleagues give ten rules, including version control, recording software versions and seeds, and sharing code. Directly applicable to the capstone reproducibility package and workflow documentation.
