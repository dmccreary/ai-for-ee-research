# Image Prompts: Volt the Border Collie

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

Paste each prompt below into your image generator **in the same conversation**
so the style stays consistent. Generate at 1024x1024, save each result under
the filename shown in `docs/img/mascot/`, then trim the padding (commands at
the end).

The character is defined in [`character-sheet.md`](character-sheet.md). If you
change a prompt, change the sheet too.

---

## 1. Neutral (`neutral.png`)

Please generate a new pose for Volt the Border Collie.
A flat vector cartoon illustration of Volt the Border Collie, a friendly
pedagogical mascot for a graduate-level textbook on using AI agents in
electrical engineering research. Volt is a black-and-white border collie with
a black back, ears and tail, and a white blaze, muzzle, chest and paws. Volt
has bright amber eyes and attentive ears, with one ear semi-folded. Volt wears
a maroon (#7A0019) bandana with a small gold (#FFCC33) lightning-bolt emblem
and a small gold whistle on a cord around the neck. Volt has an alert,
friendly, slightly wry smile. The character is compact and full-bodied,
suitable for icon-sized display.
Style: flat vector cartoon, clean lines, solid colors, transparent background
with alpha channel, suitable for embedding in educational content. No text in
image.

Volt stands upright in a relaxed, neutral pose facing the viewer, with a calm
and friendly closed-mouth smile. Paws rest naturally at the sides with no
specific gesture. The pose is balanced and unassuming — suitable as a
general-purpose or default illustration.
Filename: neutral.png

Please generate a new RGBA PNG image now with a fully transparent
alpha-channel background. The background MUST be fully transparent with an
alpha channel. DO NOT use a white, black or a checkered background.

## After generating: trim the padding

AI generators add transparent padding that makes the mascot render too small.
Run the trimmer on each file from the project root:

```sh
for f in neutral welcome thinking tip warning encouraging celebration; do
  python "$BK_HOME/src/image-utils/trim-padding-from-image.py" docs/img/mascot/$f.png
done
```
