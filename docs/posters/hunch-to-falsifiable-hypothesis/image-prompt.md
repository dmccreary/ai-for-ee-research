## Critical Rule

**This image must contain absolutely no text of any kind.** No title, no headings, no labels, no letters, no numerals, no captions, no signs, no logos, no watermark, and no readable code or equations. Sticky notes, papers, tables, and screens show only unreadable abstract marks (short colored lines and blocks) or small plain icons. Plots and matrices may show shapes and fills but no axis labels and no tick numbers. All names, descriptions, and the title are added later by an interactive HTML overlay driven by a separate data file. If any lettering or numbers appear anywhere in the picture, regenerate.

No glowing brains, no chrome robot hands, no stock-photo clichés. People are faceless or softly stylized, never photoreal faces. Agents are small friendly teal workers or neutral machine icons, never humanoid robots with faces.
