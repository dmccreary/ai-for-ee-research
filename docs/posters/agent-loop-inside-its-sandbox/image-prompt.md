## Layout Notes

- Markers sit on the visual center of the thing they name, as given in the marker map. Leave a little empty cream around each target so a marker dot and label do not hide key detail.
- No text anywhere. Use icons, padlocks, arcs, and shapes only.
- Keep the loop on the left two-thirds and the rings on the right third, with clear empty space between them. The only thing that crosses that space is the thin dashed reach arrow from the Run station.
- Locked is red with closed padlocks, and open is green with open padlocks. The agent and its loop are teal, and the hook gate is gold.
- Keep line weight, rounding, and shading (light from the upper left) consistent across the picture.
- The key idea is that an agent is a loop, and its permissions decide how far one wrong turn can reach. Make the rings and padlocks as clear as the loop.
