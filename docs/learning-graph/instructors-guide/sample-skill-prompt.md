# Sample Skill Creation Prompt

!!! prompt
    Use the /skill-creator skill to create a new skill for generating a paper in the ArXiV format.  The skill will create a new folder in a github repo project "papers" (plural) directory to store the paper.  The paper will consist the proper LeTeX files and a build process to create a high quality PDF file of the paper.  Use the following samples:

    /Users/dan/projects/microsims/paper

    /Users/dan/projects/intelligent-textbooks/papers/five-levels

    /Users/dan/projects/intelligent-textbooks/papers/self-improving-textbooks

    If the user does not provide you with sufficient information, continue to ask clarifying questions until you are confident you have enough content to generate a high quality paper.

    Create a scoring rubric of 1 to 100 to judge if the paper has enough content to be consider a high quality paper.  Include things like a clear tile, abstract, references, figures and other sections required by an ArXiV paper.
