## Overview

**AI for EE Research: From Researcher to Orchestrator** is an interactive intelligent textbook for graduate
students (MS and PhD), postdocs, and faculty in electrical engineering, computer engineering, and computer
design. It is a hands-on guide to using AI tools and agents for everyday research tasks: literature search,
brainstorming and problem framing, data analysis, simulation and testing code, and manuscript preparation.

The book's central idea is a change in the researcher's role, from doing every task personally to
*orchestrating a team of agents*: roughly 20 planning agents that explore literature, decompose problems, and
draft specifications, and 10 execution agents that write code, run analyses, build simulations, and prepare
figures. The researcher sets direction, supplies domain judgment, and decides what is true. The researcher
stays accountable for the science.

The course is practical rather than theoretical. It teaches the two building blocks that make agents reliable
in a research setting: plain **Markdown project files** and reusable **agent skills**. It also covers
**personal knowledge graphs**, verification and reproducibility, responsible and ethical use, and always-on
personal agents. Learners need graduate standing, working knowledge of one programming language (preferably
Python), and basic comfort with a command line and Git. No prior machine learning or agent experience is
required.

The content follows the 2001 revision of Bloom's Taxonomy and a concept dependency graph that sequences
prerequisites. It was built with Claude Code and the
[intelligent textbook skills](https://github.com/dmccreary/ibook-skills).

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/dmccreary/ai-for-ee-research.git
cd ai-for-ee-research
```

### Install Dependencies

This project uses MkDocs with the Material theme:

```bash
pip install mkdocs mkdocs-material
```

### Build and Serve Locally

Build the site (strict mode turns broken nav links and missing files into errors):

```bash
mkdocs build --strict
```

Serve locally with live reload:

```bash
mkdocs serve
```

Open your browser to `http://localhost:8000/ai-for-ee-research/`.

### Deploy to GitHub Pages

```bash
mkdocs gh-deploy
```

This builds the site and pushes it to the `gh-pages` branch.

### Using the Book

- Use the left sidebar to browse chapters, MicroSims, posters, slides, and appendices.
- Use the search box to search all content.
- Each chapter has a quiz and a reference list.
- Each MicroSim runs standalone in the browser. Adjust the sliders and controls to explore the concept.

### Customization

- Edit the markdown files in `docs/` to change content.
- Edit `mkdocs.yml` to change the site structure and navigation.
- Add new MicroSims under `docs/sims/<sim-id>/` with a `main.html` and an `index.md`.
- Change the theme in `docs/css/extra.css`.
